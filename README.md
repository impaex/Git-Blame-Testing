# Git-Blame-Testing
Repository used to analyse how git blame behaves on certain cases. Repository contains a generated React project.

## React Todo App

This repository contains a fully working React todo application built with Vite.

### Features
- Add new todos
- Mark todos as completed
- Delete todos
- Real-time statistics (total, completed, active)
- Responsive design with dark/light mode support

### Getting Started

```bash
cd todo-app
npm install
npm run dev
```

### Build for Production

```bash
npm run build
```

### Lint

```bash
npm run lint
```
